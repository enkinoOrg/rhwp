# 운영 HWPX 실문서 검증

## 목적

upstream 동기화 및 운영 재배포 이후 실제 업무용 HWPX 문서가 RHWP Studio에서 정상적으로 열리고 렌더링되는지 확인한다.

## 검증 환경

- 검증 일자: 2026-08-07
- 운영 URL: `https://rhwp.enkinokorea.workers.dev`
- RHWP WASM 버전: `0.8.2`
- JavaScript 번들: `assets/index-D2jcsjE_.js`
- 검증 방식: 독립 Playwright 브라우저에서 파일 선택 방식으로 로드
- 경고 모달 처리: 문서를 변경하지 않도록 `그대로 보기` 선택

문서는 브라우저의 파일 입력을 통해 RHWP Studio에 전달했으며, 문서 본문 내용은 검증 결과에 기록하지 않았다.

## 검증 결과

| 문서 | 페이지 로드 | 비표준 경고 | 콘솔 오류 | 콘솔 경고 |
| --- | ---: | ---: | ---: | ---: |
| BnBK 라벨링 작업 문서 | 2 / 2 | 2건 | 0건 | 0건 |
| 메일 검토 문서 | 1 / 1 | 9건 | 0건 | 0건 |
| KEA 최종 제안서 | 133 / 133 | 201건 | 0건 | 0건 |

세 문서 모두 전체 페이지가 로드됐다. 133페이지 문서에서도 CanvasView 로그 기준 `133/133페이지 로드`가 확인됐다.

## 경고 동작

파일 선택으로 직접 연 세 문서 모두 `HWPX 비표준 감지` 모달이 표시됐다. 확인된 경고 유형은 다음과 같다.

- `lineseg 가 문단당 1개 (한컴 textRun reflow 의존)`

이는 운영 사이트가 모든 HWPX 경고를 전역으로 숨기지 않는 현재 정책과 일치한다. 임베드 환경에서 경고 모달을 생략하려면 `postMessage`의 `loadFile` 요청에 `suppressDialogs: true`를 명시해야 한다.

## 결론

- 실제 업무용 HWPX 3건의 로드와 전체 페이지 렌더링이 정상적으로 완료됐다.
- 브라우저 콘솔 오류와 경고는 발생하지 않았다.
- 직접 파일 열기에서는 비표준 경고 모달이 정상적으로 표시된다.
- 이번 검증에서는 자동 보정, 저장 및 원본 파일 변경을 수행하지 않았다.
